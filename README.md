# 👁️ Vision Based Text Recognition Using Raspberry Pi

##  Overview
This project implements a vision-based text recognition system using Raspberry Pi. The system captures an image using a camera, extracts text using OCR (Tesseract), and converts the extracted text into speech output. It is designed to assist visually impaired individuals by enabling them to hear printed or handwritten text.

---

##  Features
-  Real-time image capture using webcam  
-  OCR using Tesseract  
-  Text-to-Speech output  
-  Supports printed text recognition  
-  Simple and portable Raspberry Pi implementation  

---

##  Hardware Requirements
- Raspberry Pi  
- USB Camera / Pi Camera  
- Speaker / Headphones  
- Power Supply  
- SD Card  

---

##  Software Requirements
- Python 3  
- OpenCV  
- pytesseract  
- pyttsx3  
- PIL (Pillow)  

---

##  Working Principle
Capture image using camera
Preprocess image (optional)
Extract text using Tesseract OCR
Convert extracted text into speech
Output via speaker

---

##  Applications
Assistive technology for visually impaired
Smart reading devices
Document digitization
Industrial label reading
